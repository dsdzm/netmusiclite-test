# 更新说明：我的歌单库新增「收藏的歌单」与推荐歌单（2026-10-18）

> 对应改动：`我的歌单` 页面从「创建的歌单 + 收藏的专辑」扩展为「创建 / 收藏歌单 / 推荐歌单 / 收藏专辑」。
>
> 目标读者：需要把本功能合并到新版上游代码的维护者。
>
> 接口依据：资料库中的《网易云音乐 Web 端 API 逆向分析报告》与《Web API 开发接入说明》（2026-10-18 实测）。

---

## 1. 背景与目标

现有「我创建的歌单」页面只有两栏：

- 我创建的歌单（`/api/user/playlist` 过滤 `creator.userId == uid`）
- 收藏的专辑（`/album/sublist`）

缺两类内容：

1. **我收藏的歌单**：用户收藏的他人歌单、官方动态歌单、年度歌单等。接口 `/api/user/playlist` 已经在同一份 `playlist[]` 里返回，靠 `subscribed=true` 区分，旧代码把整段丢掉了。
2. **推荐歌单**：匿名可用的 `/api/personalized/playlist`，可以按用户/设备推荐，并允许直接收藏。

目标：

- 「我的歌单」页按三段展示：**我创建的歌单 / 我收藏的歌单 / 推荐歌单**；「收藏的专辑」保留为第二栏。
- 推荐歌单卡片右侧提供「+」收藏按钮，收藏后立即进入「我收藏的歌单」。
- 支持「换一批」刷新推荐；推荐结果会话级缓存。
- 收藏/推荐都兼容普通手机与手表布局（不改通知/Wear 分支）。

## 2. 接口依据

### 2.1 用户歌单（创建 + 收藏）

```http
POST /api/user/playlist
uid, limit, offset → playlist[] + more
```

关键字段（登录态）：

| 字段 | 含义 |
|---|---|
| `id` / `name` / `coverImgUrl` | 歌单元信息 |
| `trackCount` / `playCount` | 曲目数 / 播放量 |
| `creator.userId` / `creator.nickname` | 创建者；`userId == uid` 即自己创建 |
| `subscribed` | 当前登录用户是否收藏；自己创建的为 `false`，收藏的为 `true` |
| `specialType` | `5` = 我喜欢的音乐，`20` = 年度歌单，`0` = 普通歌单 |

> 匿名访问时 `subscribed` 可能为 `null`，`optBoolean(..., false)` 兜底为 `false`；本页面要求登录，登录后字段正常。

### 2.2 推荐歌单（匿名可用）

```http
POST /api/personalized/playlist
limit → result[]
```

`result[]` 关键字段：

| 字段 | 含义 |
|---|---|
| `id` / `name` | 歌单 id / 名称 |
| `picUrl` | 封面（注意不是 `coverImgUrl`） |
| `trackCount` / `playCount` | 曲目数 / 播放量 |
| `copywriter` / `alg` | 推荐文案 / 算法标识，本功能暂不展示 |

### 2.3 收藏 / 取消收藏（写操作）

报告列出：

```http
POST /api/playlist/subscribe     id, t=1
POST /api/playlist/unsubscribe   id
```

> 报告明确说明写接口在未登录状态下返回 404/301，**未做进一步实测**。本项目沿用现有写接口口径 `weWrite`（PC 客户端标识 + `__csrf` Cookie），需要在真机登录态下验证。

## 3. 实现原理

### 3.1 数据模型

`PlaylistItem` 增加三个字段（都带默认值，旧构造调用不需要改）：

```kotlin
val subscribed: Boolean = false,   // 当前用户是否收藏
val creatorName: String? = null,   // 收藏歌单显示来源
val specialType: Int = 0,          // 5 我喜欢 / 20 年度 / 0 普通
```

### 3.2 一次取回创建 + 收藏，按 subscribed 分流

`NcmApi.userPlaylists(uid)` 改为：

- `limit=100`、`offset` 递增，最多翻到 1000 条；
- 用 `LinkedHashMap<id, PlaylistItem>` 去重（接口首包可能多塞「我喜欢的音乐」，不能拿返回数组长度当 offset）；
- 解析 `subscribed`、`creator.nickname`、`specialType`；
- `more=false` 或本页没有新增条目时停止。

页面分流：

```kotlin
created   = all.filter { it.isMine && !it.subscribed }
collected = all.filter { it.subscribed }
```

`mine.ifEmpty { all.filter { !it.subscribed } }` 作为 `creator` 字段缺失时的兜底，避免把收藏项混进创建列表。

### 3.3 推荐歌单

`NcmApi.recommendPlaylists(limit = 12)`：

- `we("/personalized/playlist", {limit})`；
- `picUrl → coverUrl`，`trackCount/playCount` 直接映射；
- `isMine=false`、`subscribed=false`。

`PageCache.recommendPlaylists(force)` 做会话级缓存：

- 首次拉取后缓存；
- `force=true` 用于「换一批」；
- 网络失败且非强制刷新时退回上次缓存。

### 3.4 收藏动作

推荐卡右侧「+」→ `NcmApi.subscribePlaylist(id)`：

```kotlin
weWrite("/playlist/subscribe", JSONObject().put("id", id).put("t", 1))
```

成功后：

1. **本地乐观更新**：把推荐项 `copy(subscribed=true)` 插到「我收藏的歌单」顶部；
2. 回写推荐列表里同一 id 的 `subscribed`，按钮从「+」变「✓」；
3. `PageCache.invalidatePlaylists()`，下次进页面/重进应用时重新拉服务端数据；
4. Toast「已收藏」。

不立刻重新拉 `/user/playlist`：服务端回包可能滞后，会把刚乐观插入的条目冲掉；下次进页面自然刷新。

失败只 Toast，不改本地状态，避免出现「看起来收藏了、实际没有」。

### 3.5 页面结构

`MyPlaylistsScreen`（`LibraryScreens.kt`）改为：

```text
[ 我的歌单 ] [ 收藏的专辑 ]        ← 两枚胶囊
────────────────────────────
我创建的歌单  3
  · 歌单卡片 ...
我收藏的歌单  12
  · 歌单卡片（副标题：创建者 · N 首）
推荐歌单  12                [刷新]
  · 歌单卡片（副标题：推荐 · N 首）  [+] >
```

- 卡片复用同一个 `PlaylistCard`，`action` 插槽放收藏键；
- 分区标题 `PlaylistSectionHeader` 统一「标题 + 数量 + 可选右侧动作」；
- 空态分别提示「还没有创建歌单」「还没有收藏歌单」「暂无推荐」；
- 「收藏的专辑」栏保持原实现，不动。

    var recommended by remember { mutableStateOf<List<PlaylistItem>>(emptyList()) }
    var albums by remember { mutableStateOf<List<AlbumItem>>(emptyList()) }
    var albumsLoaded by remember { mutableStateOf(false) }
    var loading by remember { mutableStateOf(true) }
    var recommendLoading by remember { mutableStateOf(true) }
    var toast by remember { mutableStateOf<String?>(null) }

        val mine = all.filter { it.isMine && !it.subscribed }

        if (toast != null) {
            delay(2200)
            toast = null

                }

                item(key = "recommend_header") {
                    PlaylistSectionHeader("推荐歌单", recommended.size) {
                        Icon(
                            NcmIcons.Refresh,
                            contentDescription = "换一批",
                            tint = if (recommendLoading) TextSecondary.copy(alpha = 0.4f) else TextSecondary,
                            modifier = Modifier
                                .size(28.dp)
                                .clip(RoundedCornerShape(50))
                                .clickable(enabled = !recommendLoading) {
                                    scope.launch {
                                        recommendLoading = true
                                        val ids = collected.map { it.id }.toSet()
                                        val fresh = PageCache.recommendPlaylists(force = true)
                                            .map { it.copy(subscribed = it.id in ids) }
                                        if (fresh.isNotEmpty()) {
                                            recommended = fresh
                                        } else {
                                            toast = "推荐加载失败"
                                        }
                                        recommendLoading = false
                                    }
                                }
                                .padding(6.dp),
                        )
                    }
                }
                if (recommendLoading) {
                    item { CenterHint("正在换一批…", Modifier.fillMaxWidth().height(120.dp)) }
                } else if (recommended.isEmpty()) {
                    item { CenterHint("暂无推荐", Modifier.fillMaxWidth().height(100.dp)) }
                } else {
                    itemsIndexed(recommended, key = { _, p -> "r_${p.id}" }, contentType = { _, _ -> "playlist" }) { _, pl ->
                        PlaylistCard(
                            pl,
                            subtitle = "推荐 · ${pl.trackCount} 首",
                            action = {
                                PlaylistCollectButton(pl.subscribed) {
                                    scope.launch {
                                        val ok = NcmApi.subscribePlaylist(pl.id)
                                        if (ok) {
                                            // 先本地落位，避免等服务端 /user/playlist 回包才显示
                                            collected = listOf(pl.copy(subscribed = true)) +
                                                collected.filterNot { it.id == pl.id }
                                            recommended = recommended.map {
                                                if (it.id == pl.id) it.copy(subscribed = true) else it
                                            }
                                            PageCache.invalidatePlaylists()
                                            // 不立即重新拉 /user/playlist：服务端回包可能滞后，
                                            // 会把刚乐观插入的条目冲掉；下次进页面自然刷新。
                                            toast = "已收藏「${pl.name}」"
                                        } else {
                                            toast = "收藏失败"
                                        }
                                    }
                                }
                            },
                        ) {
                            nav.navigateWithMotion(Routes.playlistDetail(pl.id), NavMotionSpec(NavMotionKind.Pill))
                        }
                    }
                }
            } else {
                if (!albumsLoaded) {
                    item { CenterHint("加载中…", Modifier.fillMaxWidth().height(240.dp)) }
                } else if (albums.isEmpty()) {
                    item { CenterHint("还没有收藏专辑\n专辑页点收藏即可加入这里", Modifier.fillMaxWidth().height(240.dp)) }
                } else {
                    itemsIndexed(albums, key = { _, a -> "al_${a.id}" }, contentType = { _, _ -> "album" }) { _, al ->
                        StackedCard(
                            onClick = {
                                nav.navigateWithMotion(Routes.albumDetail(al.id), NavMotionSpec(NavMotionKind.Pill))
                            },
                            navMotionKind = NavMotionKind.Pill,
                        ) {
                            CoverImage(al.coverUrl, 44.dp, shape = RoundedCornerShape(11.dp))
                            Spacer(Modifier.width(11.dp))
                            Column(Modifier.weight(1f)) {
                                Text(al.name, fontSize = 12.sp, color = TextPrimary, fontWeight = FontWeight.Medium,
                                    maxLines = 1, overflow = TextOverflow.Ellipsis)
                                Text(
                                    listOf(al.artist, if (al.songCount > 0) "${al.songCount} 首" else "")
                                        .filter { it.isNotBlank() }.joinToString(" · "),
                                    fontSize = 9.sp, color = TextSecondary,
                                    maxLines = 1, overflow = TextOverflow.Ellipsis,
                                )
                            }
                            Icon(
                                NcmIcons.ChevronRight, null,
                                tint = Color.White.copy(alpha = 0.35f),
                                modifier = Modifier.size(15.dp),
                            )
                        }
                    }
                }
            }
        }

        toast?.let { msg ->
            Box(
                Modifier
                    .align(Alignment.Center)
                    .clip(RoundedCornerShape(50))
                    .background(Color(0xCC2B2B33))
                    .padding(horizontal = 16.dp, vertical = 7.dp),
            ) {
                Text(msg, fontSize = 11.sp, color = Color.White)
            }
        }
    }

## 6. 移植到上游新版：步骤清单

1. **模型**
   - 给 `PlaylistItem` 末尾追加 `subscribed`、`creatorName`、`specialType` 三个带默认值的字段。

2. **接口层**
   - 替换 `NcmApi.userPlaylists(uid)`：`limit=100` 分页、`LinkedHashMap` 按 id 去重、解析 `subscribed`/`creator.nickname`/`specialType`。
   - 新增 `recommendPlaylists(limit)`、`subscribePlaylist(id)`、`unsubscribePlaylist(id)`。
   - 写接口沿用项目现有的 `weWrite`（PC 标识 + `__csrf`）；如果上游的写接口封装不同，换成等价的带 csrf 的 POST。

3. **缓存**
   - `PageCache` 增加 `recommendPlaylists(force)` 与 `invalidateRecommend()`。

4. **页面**
   - 用本文 5.2 替换 `MyPlaylistsScreen` 及文件末尾。
   - 保留原「收藏的专辑」`albumSublist` 分支与 `StackedCard` 专辑卡。
   - 检查上游是否已有 `PlaylistCard` 同名 Composable；有则合并参数，避免重复声明。

5. **构建测试**
   - 按第 7 节清单；至少跑 `assembleDebug`，发布前跑 `assembleRelease`。

### 合并时容易踩的坑

- **`subscribed` 只在登录态可靠**：匿名访问可能是 `null`；不要用它判断「创建」以外的业务。
- **分页 offset 不能用返回数组长度**：接口首包会多塞「我喜欢的音乐」，必须按请求的 `limit` 递增 + id 去重。
- **推荐接口封面字段是 `picUrl`**，不是 `coverImgUrl`。
- **写接口需要 `__csrf`**：`weWrite` 已带 Cookie，别换成裸 `we` 或 GET。
- **收藏成功后要清 `PageCache.invalidatePlaylists()`**，否则返回页面还是旧列表。
- **不要给推荐卡整卡加收藏点击**：`StackedCard` 已有整卡跳转，收藏键必须是独立可点击子元素（Compose 子元素会消费点击）。

## 8. 已知限制

1. **收藏/取消收藏写接口未在报告里实测**：报告明确说未登录状态下写接口返回 404/301；本实现按现有 `weWrite` 口径提交，需在真机登录态确认。若上游服务端风控变化，可能需要补 `os=pc` / eapi 口径。
2. **没有做「取消收藏」入口**：收藏列表里目前只读；`unsubscribePlaylist` 已实现，后续可在歌单详情或长按菜单接入。
3. **推荐列表来自服务端**：可能重复、可能包含不可收藏的官方歌单；失败时只提示，不做本地兜底推荐。
4. **最多翻 1000 个歌单**：极端账号（收藏数千歌单）会截断；按手表使用场景足够，需要时可调大上限。
5. **推荐缓存是会话级**：进程重启后重新拉取，不落盘。
