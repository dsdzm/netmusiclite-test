# 更新说明：收藏的歌单并入收藏栏，新增独立「推荐」页（2026-10-18）

> 前置文档：[歌单收藏与推荐](2026-10-18-歌单收藏与推荐.md)（本文调整其页面结构，接口与收藏逻辑沿用）
>
> 目标读者：需要把本功能合并到新版上游代码的维护者。

---

## 1. 背景与目标

上一版把「我收藏的歌单」和「推荐歌单」都塞进了「我的歌单」页，形成三段式长列表。实际使用中：

- 收藏的歌单本质属于「收藏」，应该和收藏的专辑放在一起；
- 推荐属于发现，应该从「我的」页独立出去，放到主页入口；
- 手表上「我的歌单」页因此过长，收藏专辑/歌单/推荐混在一起，层级不清。

本次调整：

1. 「我收藏的专辑」→ **「我收藏的专辑和歌单」**，收藏歌单移入这一栏；
2. 「我的歌单」只保留**我创建的歌单**；
3. 主页主菜单新增 **「推荐」** 入口，进入独立推荐页；
4. 推荐页包含 **推荐歌单 + 推荐新歌**，歌单推荐从「我的歌单」页移走。

  - 分区 2：我收藏的歌单（`/user/playlist` 的 `subscribed=true`）

## 3. 实现原理

### 3.1 「我的歌单」页拆分

`MyPlaylistsScreen` 状态收敛为：

```kotlin
created   = all.filter { it.isMine && !it.subscribed }
collected = all.filter { it.subscribed }
```

- 创建栏只渲染 `created`；
- 收藏栏先渲染 `albums`（收藏专辑），再渲染 `collected`（收藏歌单）；
- 收藏专辑仍按需加载（切到收藏栏才请求 `PageCache.albumSublist`）；
- 推荐相关状态、刷新、收藏按钮全部移除，页面不再请求 `/personalized/*`。

### 3.2 共享歌单组件

原来 `PlaylistSectionHeader / PlaylistCard / PlaylistCollectButton` 是 `LibraryScreens.kt` 的私有 Composable，推荐页也要用。抽到：

```
ui/components/PlaylistCards.kt
```

三个页面（创建/收藏/推荐）共用，避免复制卡片样式。

### 3.3 独立推荐页

新增 `ui/screens/recommend/RecommendScreen.kt`，`StackedCardList` 两段：

1. **推荐歌单**：`/personalized/playlist`，卡片右侧 `+` 直接收藏，右上角刷新；
2. **推荐新歌**：`/personalized/newsong?type=recommend`，点击 `PlayerEngine.playQueue` 起播并进入播放页，右上角刷新。

两段都支持「换一批」，失败时保留旧列表并 Toast。

### 3.4 接口

| 接口 | 用途 | 说明 |
|---|---|---|
| `GET /api/personalized/playlist?limit=12` | 推荐歌单 | 匿名可用；字段 `id/name/picUrl/trackCount/playCount` |
| `GET /api/personalized/newsong?type=recommend&limit=12` | 推荐新歌 | 匿名可用；`result[].song` 走现有 `parseSong` |
| `POST /api/user/playlist` | 创建 + 收藏歌单 | `subscribed` 分流（沿用） |
| `POST /api/playlist/subscribe` | 收藏歌单 | `t=1`，`weWrite` + `__csrf`（沿用） |

推荐新歌解析：

```kotlin
songs(j.optJSONArray("result"))
```

`songs()` 已兼容 `result[].song` / `songInfo` 两种包装，字段归一化不需要新增。

### 3.5 缓存

`PageCache` 新增：

```kotlin
recommendNewSongs(force = false)
invalidateRecommendSongs()
```

与 `recommendPlaylists` 同款：会话级缓存，`force=true` 用于换一批，失败退回旧缓存。

/**
 * 个性化推荐页（2026-10-18）：
 *  - 推荐歌单：/personalized/playlist，可直接收藏；
 *  - 推荐新歌：/personalized/newsong?type=recommend；
 *  - 两段都支持「换一批」，结果走 PageCache 会话缓存。
 *

@Composable
fun RecommendScreen(nav: NavHostController) {
    var playlists by remember { mutableStateOf<List<PlaylistItem>>(emptyList()) }
    var songs by remember { mutableStateOf<List<Song>>(emptyList()) }
    var playlistsLoading by remember { mutableStateOf(true) }
    var songsLoading by remember { mutableStateOf(true) }
    var toast by remember { mutableStateOf<String?>(null) }
    val scope = rememberCoroutineScope()

    LaunchedEffect(Unit) {
        playlists = PageCache.recommendPlaylists()
        playlistsLoading = false
        songs = PageCache.recommendNewSongs()
        songsLoading = false
    }
    LaunchedEffect(toast) {
        if (toast != null) {
            delay(2200)
            toast = null
        }
    }

    Box(Modifier.fillMaxSize()) {
        StackedCardList(
            modifier = Modifier.fillMaxSize(),
            title = "推荐",
            progressTotal = playlists.size + songs.size + 2,
            horizontalInsetPx = 10,
        ) {
            item(key = "playlist_header") {
                PlaylistSectionHeader("推荐歌单", playlists.size) {
                    Icon(
                        NcmIcons.Refresh,
                        contentDescription = "换一批歌单",
                        tint = if (playlistsLoading) TextSecondary.copy(alpha = 0.4f) else TextSecondary,
                        modifier = Modifier
                            .size(28.dp)
                            .clip(RoundedCornerShape(50))
                            .clickable(enabled = !playlistsLoading) {
                                scope.launch {
                                    playlistsLoading = true
                                    val fresh = PageCache.recommendPlaylists(force = true)
                                    if (fresh.isNotEmpty()) playlists = fresh else toast = "推荐歌单加载失败"
                                    playlistsLoading = false
                                }
                            }
                            .padding(6.dp),
                    )
                }
            }
            if (playlistsLoading) {
                item { CenterHint("加载中…", Modifier.fillMaxWidth().height(120.dp)) }
            } else if (playlists.isEmpty()) {
                item { CenterHint("暂无推荐歌单", Modifier.fillMaxWidth().height(100.dp)) }
            } else {
                itemsIndexed(playlists, key = { _, p -> "rp_${p.id}" }, contentType = { _, _ -> "playlist" }) { _, pl ->
                    PlaylistCard(
                        pl,
                        subtitle = "推荐 · ${pl.trackCount} 首",
                        action = {
                            PlaylistCollectButton(pl.subscribed) {
                                scope.launch {
                                    val ok = NcmApi.subscribePlaylist(pl.id)
                                    if (ok) {
                                        playlists = playlists.map {
                                            if (it.id == pl.id) it.copy(subscribed = true) else it
                                        }
                                        PageCache.invalidatePlaylists()
                                        toast = "已收藏「${pl.name}」"
                                    } else {
                                        toast = "收藏失败"
                                    }
                                }
                            }
                        },
                    ) {
                        nav.navigateWithMotion(Routes.playlistDetail(pl.id), NavMotionSpec(NavMotionKind.Pill))
                    }
                }
            }

            item(key = "song_header") {
                PlaylistSectionHeader("推荐新歌", songs.size) {
                    Icon(
                        NcmIcons.Refresh,
                        contentDescription = "换一批歌曲",
                        tint = if (songsLoading) TextSecondary.copy(alpha = 0.4f) else TextSecondary,
                        modifier = Modifier
                            .size(28.dp)
                            .clip(RoundedCornerShape(50))
                            .clickable(enabled = !songsLoading) {
                                scope.launch {
                                    songsLoading = true
                                    val fresh = PageCache.recommendNewSongs(force = true)
                                    if (fresh.isNotEmpty()) songs = fresh else toast = "推荐歌曲加载失败"
                                    songsLoading = false
                                }
                            }
                            .padding(6.dp),
                    )
                }
            }
            if (songsLoading) {
                item { CenterHint("加载中…", Modifier.fillMaxWidth().height(120.dp)) }
            } else if (songs.isEmpty()) {
                item { CenterHint("暂无推荐歌曲", Modifier.fillMaxWidth().height(100.dp)) }
            } else {
                itemsIndexed(songs, key = { _, s -> "rs_${s.id}" }, contentType = { _, _ -> "song" }) { index, song ->
                    StackedSongCard(
                        song = song,
                        isCurrent = PlayerEngine.current?.id == song.id,
                        onClick = {
                            PlayerEngine.playQueue(songs, index)
                            nav.navigateWithMotion(Routes.PLAYER, NavMotionSpec(NavMotionKind.Pill))
                        },
                    )
                }
            }
        }

        toast?.let { msg ->
            Box(
                Modifier
                    .align(Alignment.Center)
                    .clip(RoundedCornerShape(50))
                    .background(Color(0xCC2B2B33))
                    .padding(horizontal = 16.dp, vertical = 7.dp),
            ) {
                Text(msg, fontSize = 11.sp, color = Color.White, fontWeight = FontWeight.Medium)
            }
        }
    }
}

/**
 * 我的歌单库（2026-10-18 v2：收藏歌单并入收藏栏）。
 *
 * 顶部两枚胶囊「创建 / 收藏」：
 *  - 创建：我创建的歌单（含 specialType=5 我喜欢的音乐、20 年度歌单）。
 *  - 收藏：我收藏的专辑 + 我收藏的歌单（/user/playlist 的 subscribed=true，
 *    含官方动态歌单、他人歌单）。
 *  - 推荐歌单已移到主页的「推荐」入口（RecommendScreen），本页不再加载推荐。
 */
@Composable
fun MyPlaylistsScreen(nav: NavHostController) {
    var tab by remember { mutableStateOf(0) }          // 0 = 创建；1 = 收藏
    var created by remember { mutableStateOf<List<PlaylistItem>>(emptyList()) }
    var collected by remember { mutableStateOf<List<PlaylistItem>>(emptyList()) }
    var albums by remember { mutableStateOf<List<AlbumItem>>(emptyList()) }
    var albumsLoaded by remember { mutableStateOf(false) }
    var loading by remember { mutableStateOf(true) }

    suspend fun loadPlaylists() {
        val all = PageCache.userPlaylists(SessionStore.uid)
        val mine = all.filter { it.isMine && !it.subscribed }
        // 兜底：接口 creator 缺失时，至少不要把收藏项混进创建列表
        created = mine.ifEmpty { all.filter { !it.subscribed } }
        collected = all.filter { it.subscribed }
    }

    LaunchedEffect(Unit) {
        loadPlaylists()
        loading = false
    }
    // 收藏专辑按需加载：切到该栏且没拉过才发请求
    LaunchedEffect(tab) {
        if (tab == 1 && !albumsLoaded) {
            albums = PageCache.albumSublist(SessionStore.uid)
            albumsLoaded = true
        }
    }

    val total = if (tab == 0) created.size else albums.size + collected.size + 2
    StackedCardList(
        modifier = Modifier.fillMaxSize(),
        title = if (tab == 0) "我创建的歌单" else "我收藏的专辑和歌单",
        progressTotal = total + 2,
        // 2026-10-01：补上 horizontalInsetPx = 10 —— 此前缺省为 0，卡片比主页宽 20px，
        // 两页并排看宽度对不齐（主页/我喜欢/每日推荐等均为 10）。
        horizontalInsetPx = 10,
    ) {
        item(key = "switch") {
            Row(
                Modifier.fillMaxWidth().padding(vertical = 2.dp),
                horizontalArrangement = Arrangement.Center,
            ) {
                listOf(0 to "创建", 1 to "收藏的专辑和歌单").forEach { (t, label) ->
                    val selected = tab == t
                    Text(
                        label,
                        fontSize = 11.sp,
                        color = if (selected) Accent else TextPrimary,
                        fontWeight = if (selected) FontWeight.Bold else FontWeight.Normal,
                        modifier = Modifier
                            .padding(horizontal = 6.dp)
                            .clip(RoundedCornerShape(50))
                            .background(if (selected) AccentSoft else SurfaceGlass)
                            .clickable(
                                interactionSource = remember { MutableInteractionSource() },
                                indication = null,
                            ) { tab = t }
                            .padding(horizontal = 13.dp, vertical = 5.dp),
                    )
                }
            }
        }

        if (tab == 0) {
            if (loading) {
                item { CenterHint("加载中…", Modifier.fillMaxWidth().height(240.dp)) }
            } else if (created.isEmpty()) {
                item {
                    CenterHint(
                        "还没有创建歌单\n播放页 · 更多 · 收藏 可新建",
                        Modifier.fillMaxWidth().height(240.dp),
                    )
                }
            } else {
                itemsIndexed(created, key = { _, p -> "c_${p.id}" }, contentType = { _, _ -> "playlist" }) { _, pl ->
                    PlaylistCard(pl, subtitle = "${pl.trackCount} 首") {
                        nav.navigateWithMotion(Routes.playlistDetail(pl.id), NavMotionSpec(NavMotionKind.Pill))
                    }
                }
            }
        } else {
            item(key = "album_header") {
                PlaylistSectionHeader("我收藏的专辑", if (albumsLoaded) albums.size else 0)
            }
            if (!albumsLoaded) {
                item { CenterHint("加载中…", Modifier.fillMaxWidth().height(120.dp)) }
            } else if (albums.isEmpty()) {
                item {
                    CenterHint(
                        "还没有收藏专辑\n专辑页点收藏即可加入这里",
                        Modifier.fillMaxWidth().height(110.dp),
                    )
                }
            } else {
                itemsIndexed(albums, key = { _, a -> "al_${a.id}" }, contentType = { _, _ -> "album" }) { _, al ->
                    StackedCard(
                        onClick = {
                            nav.navigateWithMotion(Routes.albumDetail(al.id), NavMotionSpec(NavMotionKind.Pill))
                        },
                        navMotionKind = NavMotionKind.Pill,
                    ) {
                        CoverImage(al.coverUrl, 44.dp, shape = RoundedCornerShape(11.dp))
                        Spacer(Modifier.width(11.dp))

### 合并时容易踩的坑

- **不要在两处同时保留推荐**：推荐歌单只能出现在 `RecommendScreen`；`MyPlaylistsScreen` 里不要再请求 `/personalized/playlist`，否则重复请求/重复 UI。
- **收藏歌单只在收藏栏**：创建栏过滤条件要保持 `isMine && !subscribed`，不要把 `subscribed` 项漏进来。
- **共享组件只留一份**：`PlaylistCard` 等从 `LibraryScreens.kt` 删干净，避免同名 Composable 冲突。
- **推荐新歌的包装**：`result[]` 元素外层是 `{song: {...}}`，必须走 `songs()`，不能直接 `parseSong(result[i])`。
- **路由入口**：只加 `Routes.RECOMMEND` 不注册 composable 会白屏；两处都要加。

## 8. 已知限制

1. **推荐新歌是匿名推荐流**：未登录也能拉，但个性化程度取决于 Cookie/登录态；不做本地排序。
2. **收藏写接口仍未在报告里实测**：沿用 `weWrite` + `__csrf`，真机登录态需验证。
3. **推荐页没有「每日推荐」入口**：主页仍保留独立「每日推荐」，避免两个页面职责重叠。
4. **收藏栏顺序固定为专辑在前、歌单在后**：按标题「专辑和歌单」的顺序；如需调整只改 LazyColumn item 顺序。
5. **共享组件重构**：如果上游已经改过 `PlaylistCard` 样式，合并时保留上游样式，只借用分区/收藏键结构。
